What is JSON?

JSON stands for JavaScript Object Notation. It is used to save and share data between websites and programs.

How does JSON work?

JSON uses keys and values to organize information. A key is the name of the information and the value is the information itself.

Example of JSON

{
    "animal": "Fox",
    "name": "Red Fox",
    "type": "Wild Animal",
    "image": "fox.jpg"
}

Why do we use JSON?

JSON makes it easier to share information between different programs and websites.

What is an API?

An API lets websites get information from other websites. In this project I use APIs to get pictures and information about different animals.

What does fetch() do?

The fetch() function gets data from an API. response.json() reads the data and JSON.stringify() makes it easier to read.
